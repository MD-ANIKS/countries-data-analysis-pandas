# 🌍 Countries Data Analysis with Pandas

A beginner-friendly **Pandas Data Analysis** project that explores a real-world countries dataset to answer meaningful questions about population, democracy, regions, capitals, and political leaders.

This project demonstrates practical data analysis techniques using **Python** and **Pandas**.

---

##  Project Overview

The dataset contains information about countries including:

- Population
- Capital City
- Region & Continent
- Political Leader
- Democracy Score
- Economy
- Energy
- Healthcare
- Internet Usage
- Life Expectancy
- Military
- Environment
- Agriculture
- and many more...

Using Pandas, various queries and filtering operations were performed to extract useful insights from the dataset.

##  Analysis Performed

### Population Analysis

- Which country has the highest population
- What is the capital of the country with the highest population
- Which country has the least population
- What is the capital of the country with the least population

---

### Democracy Analysis

- Top 5 countries with the highest democracy score

---

### Region Analysis

- Total number of regions
- Number of countries in Eastern Europe
- Which African country has the highest population

---

### Political Leader Analysis

- Political leader of the 2nd highest populated country
- Number of countries whose political leader is unknown

---

### Country Information

- Number of countries having **"Republic"** in their official long name
